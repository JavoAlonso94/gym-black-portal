# Gym Black Portal

Crea la aplicación web frontend completa con Tailwind CSS para la plataforma Gym Management & Fitness Intelligence Platform (Gym Black) utilizando el logo adjunto. Debe incluir:
- Autenticación simulada: Login, Registro, Recuperación de contraseña y selección de rol (Administrador, Recepcionista, Entrenador, Cliente).
- Estética y diseño: Dark mode premium con acentos dorados y gris carbón inspirado en la identidad de Gym Black ("DISCIPLINA • FUERZA • ENFOQUE • RESULTADOS").
- Dashboard principal: Cards con KPIs accionables (Miembros activos, Asistencias hoy, Ingresos hoy, Adeudos), gráficas interactivas de ingresos y afluencia, alertas de membresías próximas a vencer y actividad reciente.
- Módulos interactivos simulados con datos realistas:
  1. Clientes y membresías: Directorio con expedientes, estados de membresía (Activa, Vencida, Congelada), filtros y ficha de cliente.
  2. Control de acceso QR: Escáner interactivo simulado que valide código QR y muestre feedback de acceso autorizado o rechazado.
  3. Punto de Venta (POS) y Caja: Catálogo de productos (suplementos, ropa, bebidas), carrito de compras, cálculo de total y simulación de ticket de venta y corte de caja.
  4. Rutinas y ejercicios: Catálogo de ejercicios clasificados por grupo muscular y constructor visual de rutinas.
  5. Perfil y progreso: Registro de medidas corporales y gráficas de evolución física.
- Todos los componentes, filtros, modales y navegación deben funcionar de manera fluida en el frontend.
